# 初階職業（首批正式名冊）

本文件依使用者已確認的職業討論，以及 2026-10-06「做四個初階職業的正式名冊與唯讀核對畫面」指示，收錄本次四職業的正式資料。工程交付與待驗證狀態見 [Phase 33 第二切片](../development/PHASE_33_CLASS_CATALOG.md)。UI 原型的樣本裝備、技能門檻、角色數值及裝備欄位不因此成為正式規則。

## 1. 共通方向

- 角色共用角色等級，不為每個職業重新練級。
- 已開放的初階與進階職業可以在戰鬥外切換。初始開放哪些職業、取得與切換命令的完整契約仍待確認；名冊收錄不代表角色已開放全部職業。
- 只有目前職業的屬性倍率及被動生效，不疊加其他已開放職業的加成。
- 職業不限制玩家裝備哪種技能；技能本身仍有屬性等需求。適配職業與技能的加成由明確規則決定。
- 可有綁定職業或職業特化的裝備，但具體名單、欄位、加成與切換失效處理留待後續規格。
- 學會指定數量的特定職業技能可作進階解鎖方向；具體職業、技能計數、門檻與取得流程尚未定案。

|---|---|---|---|---|---|

每個職業其餘五項屬性倍率均為 ×1。被動名稱是本次名冊的顯示標籤，不能藉名稱推導額外能力。四項被動本切片只收錄資料與說明，尚未接入正式戰鬥計算。

## 3. 屬性需求與技能加成

使用者確認的計算方向：

- 資格數值 = `floor(固有屬性 × 目前職業倍率) + 生效裝備加成`。
- 最終屬性 = 資格數值 + 生效技能加成。
- 技能加成不參與自身或其他技能／裝備的需求判斷，避免技能互相支撐門檻。

本切片不計算或改寫任何角色屬性。固有屬性組成、正式裝備生效順序、職業切換後不合格配裝的完整處理、HP／MP 上限同步，須在配裝／轉職切片確認後實作。原型中智慧 15、技能 +1、裝備 +2／+3 等樣本數值不收錄。

## 4. 施法資格邊界

魔術師職業、智慧倍率與魔力資質都不自動賦予直接施法資格。直接施法資格的取得／生成方式仍待定。魔法書另須符合自身使用條件；施法節約只作用於原本已符合資格的直接施法或魔法書施法，不擴大到捲軸或其他魔導具。

魔法書詠唱回合的 ×1.25 是不同規則，不等於職業智慧 ×1.25。詳見 [魔法](magic.md)。

## 5. 仍待定

- 起始技能、裝備、武器熟練、初始職業開放與創角選擇流程。
- 正式技能清單、技能分類／標籤、屬性門檻及技能加成。
- 劍術傷害 +10% 與護甲／暴擊／其他倍率的順序與取整。
- 施法節約後總 MP 如何分配到多回合；只確定總額向上取整、正成本最低 1、零仍為零。
