本文件依使用者已確認的職業討論，以及 2026-10-06「做四個初階職業的正式名冊與唯讀核對畫面」指示，收錄本次四職業的正式資料。工程交付與待驗證狀態見 [Phase 33 第二切片](../development/PHASE_33_CLASS_CATALOG.md)。UI 原型的樣本裝備、技能門檻、角色數值及裝備欄位不因此成為正式規則。

2026-10-10 使用者另選 A，批准首批起始配套的門檻、加成及護甲值作正式首版，見 [起始配套 v1](starter_kits.md)。該文件列明已確認的欄位、需求來源及失效處理方向；第七切片只收錄名冊與唯讀核對，未實作發放、轉職、配裝或戰鬥。以下第二切片範圍敘述保留當時界線，未定事項依下方修訂。

## 1. 共通方向

- 角色共用角色等級，不為每個職業重新練級。
- 已開放的初階與進階職業可以在戰鬥外切換。2026-10-07 使用者選擇 A：創角時從四個初階職業選一個作為目前職業，初始只開放所選職業；其他職業的取得條件與切換命令完整契約仍待確認，名冊收錄不代表角色已開放全部職業。
- 只有目前職業的屬性倍率及被動生效，不疊加其他已開放職業的加成。
- 職業不限制玩家裝備哪種技能；技能本身仍有屬性等需求。適配職業與技能的加成由明確規則決定。
- 可有綁定職業或職業特化的裝備，但具體名單、加成與正式命令／保存留待後續規格；目前精簡欄位及一般失效保留／停用方向見起始配套文件。
- 學會指定數量的特定職業技能可作進階解鎖方向；具體職業、技能計數、門檻與取得流程尚未定案。

## 3. 屬性需求與技能加成

使用者確認的計算方向：

- 裝備需求數值 = `floor(固有屬性 × 目前職業倍率)`，不含任何裝備或技能加成；技能資格數值再加生效裝備加成。此裝備需求區分依 2026-10-10 使用者已確認方向，見 [起始配套](starter_kits.md#4-已確認的需求與配置方向)。
- 最終屬性 = 資格數值 + 生效技能加成。
- 技能加成不參與自身或其他技能／裝備的需求判斷，避免技能互相支撐門檻。

第二切片只收錄職業名冊，不計算或改寫角色屬性。固有屬性先合併基礎、創角分配與種族加成，再乘目前職業；HP／MP 採最終屬性。2026-10-07 使用者撤回保留缺少量及 B 方案，確認穿上裝備提高 HP／MP 上限時，目前值不變；使用者其後回覆「確定」，職業與裝備採同一套容量政策：提高上限不恢復目前值，降低時只截掉超過新上限的部分，詳見 [角色系統](character_system.md)。2026-10-10 已確認裝備資格獨立判斷、技能加成容量及失效保留／停用方向，首批數值另在起始配套 v1 收錄；正式狀態同步尚未接入。其他原型樣本不因本次確認自動成為正式內容。

## 4. 施法資格邊界

魔術師職業、智慧倍率與魔力資質都不自動賦予直接施法資格。2026-10-07 使用者確認玩家創角時獨立隨機生成資格，完成後揭曉並固定；五族統一 1%，職業與魔力資質不影響此機率。本切片只保存並揭曉資格，具體血脈來源標為「尚未揭露」，不生成身世或隱藏來源，AI 不得自行補定；第五切片獨立創角紀錄已實作準備、待驗證。魔法書另須符合自身使用條件；施法節約只作用於原本已符合資格的直接施法或魔法書施法，不擴大到捲軸或其他魔導具。

魔法書詠唱回合的 ×1.25 是不同規則，不等於職業智慧 ×1.25。詳見 [魔法](magic.md)。

## 5. 仍待定

- 起始技能、裝備與武器熟練的首批內容及數值已在 [起始配套 v1](starter_kits.md) 定案；發放、可變配裝保存、其他職業取得條件與正式冒險接入仍待契約。
- 首批四項能力以外的技能清單、分類／標籤、門檻、加成，以及全部正式能力的戰鬥數值仍待定。
- 劍術傷害 +10% 與護甲／暴擊／其他倍率的順序與取整。
- 施法節約後總 MP 如何分配到多回合；只確定總額向上取整、正成本最低 1、零仍為零。
- 進階職業、解鎖門檻、職業特化裝備，以及已確認失效保留／停用／恢復方向的正式命令與保存契約。
