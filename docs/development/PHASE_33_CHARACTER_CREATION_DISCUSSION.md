## 已確認：首次創角 HP／MP

使用者對「首次創角滿 HP／MP，之後依已確認規則處理」明確回覆「接受」。

- 正式角色建立完成時，目前 HP／MP 各等於當時推導的最大值，只設定一次。
- 例：推導最大 HP 55、最大 MP 60，初始為 55／55、60／60。這是公式示例，不是全部角色的固定數值。
- 之後受傷或消耗、重新整理、存檔與載入不觸發重新初始化。
- 換職業或裝備提高上限仍不補充資源；降低時只截掉超過新上限的部分。零 HP 不因容量變更復活，不保存隱藏缺少量。
- 這項決定不擴大到升級、技能或暫時效果政策。

權威規則已同步 [角色系統](../gameplay/character_system.md)；討論當時工程與保存尚未接入，目前準備狀態見交付。

## 已確認：保存成功後揭曉、同一次建立可安全重試

使用者對以下流程回覆「滿意」：

1. 選種族、職業及分配屬性時只編輯草稿，尚未抽取隱藏結果。
2. 最後確認建立時，由系統生成魔力資質、直接施法資格及龍裔龍息元素，連同角色資料一起保存。
3. 保存成功後才揭曉；重新整理或重新讀取顯示同一角色，不重新抽取。
4. 若已保存但網路中斷，重試同一次建立取回原結果，不重複建立角色。結果未知不冒稱確定失敗；必須保留同一次建立的身分以查詢或重試。
5. 若確定保存失敗，保留輸入供手動重試，不顯示未保存的抽取結果。

上述流程確認當時尚未決定角色數量，其後的單角色／正式版多角色決定見下節；刪除、替換或重新開始的完整正式版政策，以及現有 Save 遷移沒有在本次批准。固定生成與保存仍由系統決定，LLM 不參與抽取或改寫。具體工程與故障守衛見實作確認稿；尚未執行工程驗證。
