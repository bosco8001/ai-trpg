## 其餘待定

第一階段的持久備份、識別碼、查詢、下載及失敗契約已批准。以下涉及套用的細節仍須在第二階段實作前另行確認；第一階段的批准不代表提前批准這些寫入行為。

- 套用時重新讀取原稿、核對指紋與規則版本、重建及整筆驗證候選的原子契約；Phase 31 只核對準備時刻。
- 來源自身的 lineage 一致性與套用前核對契約；不將唯讀槽預覽自動當作可套用授權。
- 版本／generation 與敘事寫入的競爭守衛、來源在備份／確認／套用間改變的處理。
- Memory 與 PostgreSQL 原子套用的單次失敗、程序重啟及崩潰語義；不以 Phase 31 備份成功推定套用能力。
- 套用結果的持久契約、重啟後無法確認時的處理，以及完成報告留存。
- 套用前再次確認 UI、候選及完成報告的顯示與下載。

沿用 R02 的兩種有限候選，不因 R03 自動加入缺值補造、跨來源猜測、LLM 修復、正常 Load 暗中更正或備份還原。新增修復類型須另行確認。
