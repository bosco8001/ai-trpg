## 正在確認

第 3 項：修復前備份保存位置與持久性。

- A：PostgreSQL 模式保存至資料庫，Memory 模式保存至伺服器本機檔案。
- B：兩種模式都保存至伺服器本機檔案。

兩個選項都以伺服器重新啟動後仍能保留為目標；詳細保存／故障契約仍待定。以上是選項，尚未記錄使用者選定。

## 其餘待定

- 備份的保存位置、持久性、保留／取回方式與失敗處理。
- 套用前重新讀取原稿、核對指紋與規則版本、重建及整筆驗證候選的契約。
- 目前資料與全域存檔槽的角色、Run／world／lineage 核對政策；不將唯讀槽預覽自動當作可套用授權。
- 版本／generation 與敘事寫入的競爭守衛、來源在備份／確認／套用間改變的處理。
- Memory 與 PostgreSQL 的原子操作、單次失敗與程序重啟語義。
- 重複請求、回應遺失後的查詢與重試、修復識別及報告留存。
- 確認 UI、備份／候選／結果報告的顯示與下載，以及實作的階段切分。

沿用 R02 的兩種有限候選，不因 R03 自動加入缺值補造、跨來源猜測、LLM 修復、正常 Load 暗中更正或備份還原。新增修復類型須另行確認。
