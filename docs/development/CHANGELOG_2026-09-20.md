# Sync Changelog — 2026-09-20

## Synchronized confirmed decisions
- Evasion changed from fixed `10 + Dexterity modifier` to opposed `D20 + Dexterity modifier`.
- Hit condition finalized as `Attack Check >= Evasion Check`.
- Natural 1 is not an automatic failure.
- Critical requires a successful hit first; raw attack D20 19–20 then gives ×1.5 damage.
- Initiative ties reroll D20.
- Melee cannot bypass an occupied enemy front row.
- Ranged weapons and single-target attack magic may directly target the back row.
- AoE targets one row and resolves each target separately.
- Player front/back row movement consumes a main action.
- Dragon Breath can crit and is reduced by normal armor.
- Opening Bag/Party does not consume a turn; using an item does.
- Companions use semi-autonomous combat behavior.
- Combat AI narrates; the system owns mechanics.
- Combat UI layout and dark-fantasy visual direction finalized.
- Action-order UI rotates visually after each actor.
- Non-player actors require readable pacing pauses.
- Mobile responsive behavior is required.
- Human magical aptitude distribution synchronized into `races.md`.
- Magical aptitude explicitly separated from direct-casting eligibility.
- Magic skill slots clarified as six active-skill slots.
