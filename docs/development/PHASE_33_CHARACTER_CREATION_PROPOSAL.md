## 單一目標

建立並保存一份正式來源的 Lv.1 角色建立紀錄，保存成功後揭曉固定結果，讓使用者重新整理及重啟伺服器後仍能核對同一角色。就像先完成並收好角色卡，起始行囊與冒險另分切片。

## 使用者已確認規則

- 五族正式名冊 v2、四初階職業名冊 v1；六屬性基礎 8、自由分配 12 點、單項分配最高 14，人類另分配 2 點。
- 先加種族，再乘目前職業倍率並向下取整。Lv.1、無裝備／技能加成的建立紀錄共用第四切片正式推導；不把樣本 40／55、48／60 等數值當成正式初始值。
- 創角選一個目前職業，初始只開放所選職業；其他職業取得條件仍待確認。
- 魔力資質依已定種族分布生成；直接施法資格另外獨立抽取，五族統一 1%，職業與資質不影響資格機率。
- 只揭曉是否具有資格，血脈來源為「尚未揭露」，不生成隱藏身世，LLM 不得補定。
- 龍裔龍息目前火／冰／雷各 1／3，生成後永久固定；後續擴充另議。非龍裔沒有龍息元素。
- 目前 HP／MP 首次設定為推導上限，只初始化一次。保存／讀回不補充資源；此紀錄不是可編輯的實際遊戲資源面板。
- 草稿不抽取隱藏結果；最後確認時由系統生成並一起保存，成功後才揭曉。同一次建立重試不重複建立或重抽已保存結果。
- 保存建立時名冊版本、分配、生成結果與初始資源，名冊更新不自動改寫原始紀錄；角色後續成長不因此被凍結。
- 本切片先保存一名角色，完成後只核對；正式版必須支援多名獨立角色與列表，後續具體上限與 Run 綁定另訂。

## 工程與保存提案

- 角色建立紀錄與現有 `game_states`、三槽 `save_slots`、修復封存分開。新增專用資料表與 repository，不覆寫 TEST 目前角色、不建立新 Run，不改現有 Save 格式。
- 每份紀錄有自己的角色 ID、建立時間、格式／推導規則版本及名冊版本，不使用 TEST 身分冒充正式角色。本切片的單角色限制由伺服器與資料庫一致守衛；避免兩個分頁同時建立兩份。未來多角色保留不同角色 ID 的保存結構，新增列表與放寬建立限制另作小階段。
- 正式建立／保存使用 PostgreSQL。沿用現有 `DOMAIN_STORAGE=postgres` 與設定，不新增或改動憑證；服務重啟後仍讀回原紀錄。Memory 模式顯示需要 PostgreSQL 才能保存，本切片不提供會在重啟後遺失的建立成功畫面；可注入記憶體 repository 供 Grok 隔離測試，不冒稱持久化。
- 一次建立身分加請求內容核對用於重試；伺服器產生角色 ID 與結果。相同建立身分且相同輸入取回原紀錄，身分相同而輸入不同明確拒絕；不同建立身分遇到已有角色也拒絕新增，UI 可讀回原角色。
- 使用系統隨機來源與整數權重，龍息以三等份取樣，避免百分比取整造成偏差。可注入測試亂數，但正式 HTTP 請求與環境開關不接受指定抽取結果。
- 資料庫完整保存成功才回傳生成結果；逾時／斷線／提交結果未知時不宣告失敗或換身分重抽。前端保留同一次建立身分與必要輸入，手動查詢／重試；重新整理後先查已保存角色。
- 回應與讀回紀錄嚴格驗證格式、版本、正式引用、分配、種族資質合法性、資格、龍息、推導與初始資源的一致性；非法或未知資料不偷偷套 TEST／空值或填補。新畫面的建立回應另核對載入的正式名冊，第四切片舊 Info 不因本稿改標已解決。
- 保存生成結果與必要名冊快照資料，以便核對建立時資訊；新建要求目前支援版本，讀回原始紀錄依其格式／推導版本驗證，不用新名冊自動重算覆蓋。未支援或損壞資料固定提示不可讀，不刪除或修改原資料。
- 沿用現有單機服務範圍，不新增帳號、登入或多人連線；建立身分、保存範圍由伺服器控制，HTTP 不接受任意玩家或保存範圍覆寫。

## 手機畫面與操作提案

- 系統面板提供角色建立／已建立角色核對入口，明確標示尚未接入正式冒險。既有角色屬性樣本核對工具保留原用途。
- 以 Full-screen Sheet 分步顯示：選種族／職業 → 分配屬性與人類種族點 → 最後核對 → 保存中／結果。只顯示當步主要操作，完整名冊與詳細屬性透過 Sheet 或可展開區域閱讀。
- 生成前不顯示個別角色最終資質、資格、龍息或可反推資質的最終 MP；可閱讀正式分布說明。尚未完整分配不得確認建立。
- 保存期間避免重複提交；關閉畫面不假設伺服器已取消。再次開啟先查保存狀態，未知結果仍保留原建立身分。
- 結果畫面顯示角色 ID／建立時間、種族、所選職業、分配及最終六屬性、滿 HP／MP、固定生成結果與版本；詳細計算放展開區，不堆滿主畫面。
- 不新增出身設定或自動故事身世；角色名稱等未定內容不作此切片前置，使用既有正式名稱與系統角色識別核對。
- 三項指定 UI 技能共同沿用已接受的手機設計：game-ui-ux 處理流程／焦點／狀態同步，ui-ux-pro-max 處理資訊層級／響應式／無障礙，apple-design 處理字體／間距／回饋／短動畫；不重做整套視覺方向。
