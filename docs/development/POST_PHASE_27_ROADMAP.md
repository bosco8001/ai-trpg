## 判讀方式

- **已定待接入**：Canonical 文件已描述核心規則，但程式只接通部分流程或仍用 TEST 資料。
- **先決定**：數值、內容或生命週期尚未定案；須先確認相關部分，才能實作。
- **後續承諾**：已明列未來要處理的系統；其中 Save / State Repair 是 FUTURE REQUIRED，其餘 Future 不代表已承諾全部在 v1 完成。
- **範圍候選**：產品方向需要，但玩法與交付範圍未正式定義；不能因出現在此處就自行擴大遊戲。

順序以先保護資料、再建立真實角色與可結算戰鬥、之後補故事互動為原則。**順序不是所有項目之間的硬依賴**；硬依賴寫在每列。被待定規則擋住時，可以由使用者選擇下一個不受影響的小項，不可先猜規則。正式 LLM adapter 也可在確認供應商後提早獨立接入，不需等待所有遊戲功能。

## 較後段的獨立候選

這些不能當作前面都做完後自動開始的 phase。每項仍須先確認必要性、內容與單一目標。

| 項目 | 先具備什麼 | 未定範圍 |
|---|---|---|
| 通用狀態／持續效果 | 權威傷害／治療、明確計時、Save schema | 毒／暈眩／封魔／buff 的觸發、疊加、到期、戰後保留；有需要時可為 R15／R27 提早做有限切片 |
| 長期隊伍站位／編隊 | 正式隊伍與遭遇名冊、Save schema | 初始站位來源、戰鬥外編隊、戰後是否保留；既有戰鬥內換排不代表長期 Formation 已實作 |
| 魔導武器／魔導具 | 裝備、MP、法術效果、正式內容 | 每件的效果／觸發／MP 不足處理；不加入核心獨立 MP，也不免費賦予所有矮人工藝技能 |
| 幻術 | 探索事實、NPC／目標與感知邊界 | 只能欺騙感官，不能讀心／控制意志；先核准一個實際效果 |
| 空間儲物 | inventory／所有權／存檔 | 容量、取放、目標與時間限制 |
| 傳送 | 正式位置／world 引用 | 專用魔導具或稀有捲軸、距離／目的地／網路限制；普通法師不能隨手傳送 |
| 神物級復活 | 死亡角色保存、資源與隊伍規則 | 來源、代價、身分／資源恢復、重入隊伍；一般治療不可復活 |
| 永久 Enemy／Encounter 狀態 | R21、R24、R27 | 逃跑後敵傷／療傷／再遇、組成／重生／保存；本場 final facts 不等於永久世界事實 |
| 戰鬥統計／重播 | R24 與足夠版本化機械事實 | 先做只讀統計，再決定重播範圍；保留不同 completion，不能用 AI 猜回放 |
| 種族文化／地區／進階互動 | 核准世界內容與首個場景 | races §11 未定世界細節與專屬職業／裝備方向，不能自行補永久 lore |
| 正式部署／朋友使用 | 先決定私用或多使用者；正式新 Run、存檔備份與真實 adapter | API 權限、角色／Run 隔離、金鑰／成本、日誌與恢復；多個 campaign／多人即時連線不是既定規則 |
| UX 與後續平衡 | 功能與資料已經真實可操作 | 速度設定、快轉、傷害／死亡呈現、種族／HP／MP playtest；數值調整由使用者驗收決定 |
