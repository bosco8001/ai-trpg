## 兩條有限規則

### 活動標記

`combat=null` 對應 `activity=outside-combat`。完整、合法的 Combat 存在時對應 `activity=in-combat`，包含 active、ended-but-unsettled 與 Game Over。

只更正已存在且是上述合法列舉值的 `activity`。不建立、刪除 Combat，不結算、不清除詠唱、不猜戰鬥結果。來源 Combat 必須完整，所有引用及機械內容在整筆候選驗證時通過。

### 玩家 MP 相容欄位

以同份資料的 `character.id` 唯一對應 `phase26.characters[].characterId`，該長期玩家的合法 `currentMp` 是外層 `character.currentMp` 的同步來源。

目標 MP 已存在、是非負安全整數且不超過該長期角色 `maxMp`。來源長期角色的 HP／MP、上限與生命狀態必須合法；身分不唯一、找不到角色或來源資源不合法都拒絕。

不改 `phase26.characters` 或 Combat 的權威資源。Combat MP 可與長期 MP 不同；不強迫相等，不從 Combat、其他槽、故事或最新 Settlement 文字推算 MP。

## 來源、驗證與拒絕

- 限完整 Phase 26 schema v2 的目前資料與 Save Format v2。舊 TEST v1、未知正式舊資料及未來版本保持受阻；原有正常 Load 的已接受映射保持原狀。
- 不把 hydrate、舊格式映射或 TEST 補值當成修復證據。驗證器若需要補值、正規化或更改其他內容，拒絕候選。
- 目前資料保留全部 History、敘事 ledger、generation 與序號上限；Save 保留自己的完整內容及列 metadata，不混入目前資料。
- 候選只是原始資料上最多兩欄的暫時更正。使用既有 domain／Save v2 驗證器檢查，並確認其輸出沒有更動允許欄位以外的內容。不呼叫一般 Save 重建候選。
- 兩項更正一起驗證；若仍有非法資源、身分／世界／隊伍／敘事引用衝突等問題，整筆受阻，沒有局部候選。
- 缺目前資料與空槽明確區分；不建立新資料。暫時讀不到或超限不等於資料損壞。
- 只列已確認原因，不保證一次找齊全部錯誤。整筆驗證失敗但尚無可精確定位的原因時，明示整筆來源仍未通過驗證。
- JSON 數字先核對原始字面量是否確實代表安全整數，不能先因 JavaScript 四捨五入而變成合法證據。保留來源文字作指紋，不重寫原稿。

## 預覽與時效

- 四項各自顯示擷取時間、狀態、可確認的資料／狀態版本。各項為獨立讀取切面，不是跨來源的一致備份。
- 有效候選逐欄顯示原值、建議值、規則與來源欄位／值，並標示「唯讀預覽，尚未套用」及擷取時整筆驗證通過。
- 通過驗證不代表能在目前 Run 載入、仍是最新資料或已獲使用者驗收。
- 完整原始來源 SHA-256 包含來源種類、配置角色範圍與來源識別，不只看 revision；來源內的 ledger、History、序號上限、generation 及保存時間皆參與。候選 SHA-256 另涵蓋暫時更正後的完整資料。指紋只供核對，不是來源認證或永久套用憑證。
- 前端已知狀態／敘事變動會使目前資料結果失效。Save 只失效該槽；Load 使目前資料失效或隨畫面替換清除。存讀檔操作前後都保守失效，回應遺失亦不宣稱成功或自動重送。
- 取得預覽期間的變動也保守標為過期。使用者手動重新取得才更新，不輪詢、不自動換掉閱讀中的差異。
- 其他分頁／程序的變動未必被即時察覺。結果始終只代表擷取時刻；R03 未來套用必須重新比對完整來源與相關版本／lineage，不能信任舊預覽。

## 入口與工程限制

- 系統面板沿用探索、戰鬥、結果與主選單入口；初始狀態讀取失敗畫面亦可獨立開啟。不要求健康檢查、存檔清單或備份成功。
- 可繼續遊戲，不推進回合、不改 revision、不修改來源、不保存候選到伺服器，也不等待未保存敘事。
- 預覽使用 GET、no-store，不接受客戶端指定角色／世界或其他來源。沒有套用方法及按鈕。
- 單項原始資料分析上限 10 MiB；四項各自拒絕超限，不截斷、不略掉故事或 ledger。完整回應上限 64 KiB，回應只含差異、原因與指紋，不含完整原稿／故事。
- 本次低風險工程設定為整次接收 30 秒、手動重試；PostgreSQL 專用唯讀連線池取得連線一秒、查詢兩秒，不改一般遊戲連線設定。
- 取消或關閉時停止前端接收並捨棄專用連線；不保證 PostgreSQL 查詢立即停止，仍受自查詢開始計算的兩秒 `statement_timeout` 限制。離開後的舊回應不能顯示結果。
- 等待、完成及失敗不主動搬移焦點；同步旗標阻止重複觸發。原生按鈕保留可聚焦狀態並以 `aria-disabled` 表示忙碌。
