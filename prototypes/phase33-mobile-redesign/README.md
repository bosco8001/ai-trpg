本次只展示角色配裝範圍的新視覺語言。沒有重做正式戰鬥 HUD、敘事、背包、完整角色生成或冒險畫面。角色樣本沒有假 HP／MP、假探索行動或假戰鬥進度。

## 保留的確認規則與暫用資料

原型的玩法範圍沿用使用者確認的試作方向，沒有把視覺提案升級成 Canon：

1. 劍士力量／弓箭手感知／斥候敏捷／魔術師智慧，主要屬性 ×1.25，其餘 ×1；戰鬥外切換已開放職業，共用角色等級。
2. 資格 = floor（固有屬性 × 職業倍率）+ 生效裝備；最終屬性 = 資格 + 生效技能加成。技能加成不參與自己或其他技能門檻。
3. 通用單項 +2，職業特化單項 +3、指定職業生效；一個裝備示範欄位，並非正式裝備欄位數。
4. 四個已學技能：重斬力量 15、穿透箭感知 15、分身術敏捷 15、火球術智慧 15，各自生效加成 +1；最多六格，暫不允許同技能重複配置。
5. 失效技能／裝備保留配置，不提供加成。恢復條件後重新生效，不因轉職刪除或遺忘。
6. 職業不鎖死所有技能。武器／施法獨立條件在此樣本假設已滿足；魔術師不會自動賦予直接施法資格。
7. 職業被動只展示已討論說明：劍術技能傷害 +10%；射擊技能攻擊判定 +1；閃避判定 +1；符合資格施法總 MP -10%、向上取整、正成本最低 1、零仍零。未模擬戰鬥效果。

所有名稱與門檻／加成是這次試作資料；固有屬性預設 12、輸入 1–99 是任意成長角色示範，非正式創角或永久上限。進階職業、解鎖條件、裝備／技能完整需求、傷害順序、普通攻擊適配、MP 分回合、HP／MP 同步都不在本次範圍。

## 操作契約

- 職業與裝備各自預選，進入核對頁才顯示變化，點套用後一次改配置並重算。返回保留該任務的選擇；關閉或 Esc 丟棄未套用選擇。
- 技能選擇在同一 Sheet 堆疊內進行，不疊多個 dialog。保存或清空會返回主畫面；取消不修改。
- 單一 `state` 保存目前配置，`derive` 計算資格／最終／有效狀態；沒有另一份職業狀態、輪詢、請求或持久化。
- 固有屬性先填草稿、保存時逐項驗證；非法輸入有欄位訊息與第一個錯誤的焦點，不部分保存。返回或關閉不保存草稿。
- 更新技能格會重建其 DOM；關閉焦點用穩定入口 key 找回目前元素，避免把焦點交給已移除元素。
- 不是可拖曳 Sheet，沒有假拖曳把手或 swipe 提示。CSS discrete transition 不支援時，原生立即關閉；待 Grok 比較 Safari／Chrome，未宣稱跨瀏覽器動畫相同。
- `dialog` 使用原生 modal 焦點限制；沒有遊戲手把導覽、瀏覽器 history／深層 URL 路由。手機 Back 系統手勢未實作成 Sheet Back，必須交由後續正式整合討論。
- 主要畫面用 viewport 高度與安全區，Header／底部導航固定。一般手機希望核心配置可直接查看；短高度與大字時允許內容區捲動，不能以裁切／縮小字體強塞一屏。
- 本頁操作紀錄最多 20 筆，只在記憶體；不是遊戲保存或審計紀錄。回饋提示 4.5 秒消失，已套用狀態持續顯示。
- 載入控制只有設計展示中的手動樣式開關，aria-busy 告知展示狀態；沒有假非同步套用或等待時間。
